# PlanIA

Agenda personal responsive para móvil y escritorio.

## Arquitectura prevista

- React con Vite.
- Supabase para autenticación, base de datos y archivos, con cuentas independientes de NOSOTROS.
- Vercel para despliegue y vistas previas.

## Estado

Repositorio inicializado. Aplicación pendiente de implementación y configuración de servicios.

## Reglas principales

- Registro sujeto a aprobación de administrador.
- Agendas privadas por usuario.
- Vacaciones y asuntos propios: todos los días del intervalo, incluidos fines de semana, excluyendo festivos del usuario.
- Horarios predeterminados configurables por tipología; guardia nocturna inicial de 20:00 a 08:00 del día siguiente.
- Exportación desde agenda en iCalendar, PDF y Excel.
